# Dynatrace Observability Lab

Laboratório prático de estudos em monitoramento e observabilidade utilizando Dynatrace, Docker e EasyTravel.

## O que estou estudando

* Hosts e métricas
* CPU e memória
* Problems e Events
* Alertas e thresholds
* Maintenance Windows
* Notificações
* Davis AI
* Dynamic Baseline

## Objetivo

Desenvolver conhecimentos práticos em monitoramento, observabilidade e troubleshooting utilizando Dynatrace.
