# Docker + EasyTravel

Neste laboratório, estou utilizando Docker e o ambiente EasyTravel para estudar conceitos de monitoramento e observabilidade com Dynatrace.

## O que estou praticando

* Containers
* Monitoramento de aplicações
* Integração com Dynatrace
* Identificação de problemas e métricas

## Objetivo

Entender na prática como uma aplicação executada em containers pode ser monitorada utilizando uma plataforma de observabilidade.
